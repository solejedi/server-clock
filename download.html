GitHub에서 다운로드

지원 OS: Windows 10 / 11 (64-bit 권장)

설치 및 실행 안내

  • 위 링크에서 GitHub 배포 페이지로 이동합니다.
  • Assets 항목에서 최신 버전의 .zip 또는 .exe 파일을 클릭하여 다운로드합니다.
  • 다운로드한 파일의 압축 해제 후 프로그램을 실행합니다.
  • 별도의 복잡한 설치 과정 없이 즉시 서버 시간 측정이 가능합니다.
가장 정확한 서버 시간을 측정하는 서버클락 공식 사이트입니다.
